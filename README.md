#  Это учебный проект по изучению сетевого взаимодействия и сбора телеметрии в изолированной среде. Демонстрирует принципы работы клиент-серверных приложений на Python.
**ВАЖНО:** Этот проект создан исключительно для образовательных целей. так же его использование в злонамеренных целях невозможно из за того что код лишь показывает концепцию(PoC-Proof of Concept) и не имеет средств защиты.
Использование в реальных системах без разрешения владельца запрещено и может быть незаконным
## Описание.  
**ПРЕДУПРЕЖДЕНИЕ**: этот код написан для работы на windows и нигде больше код работать не будет.  
этот репозиторий является прямой демонстрацией того как работают простейшие инструменты для
удаленного сбора телеметрии и последующей отправки на сервер(github)  
он способен:  
- делать скриншоты экрана.  
- логировать нажатие клавиш(кейлоггер).  
- собирать информацию об операционной системе компьютера.  
- получать информацию о текущей дериктории.  
- завершать работу в случае обнаружения аномального поведения со стороны пользователя(обнаружение песочниц).  
- загружать собранную информацию в папку data в текущем репозитории.  
все модули загружаются динамически во время работы программы что не требует перекомпиляции при добавлении функционала.  
все внешние библиотеки используемые в модулях загружаются прямо в процессе запуска по необходимости позволяя запускать код имея лишь интерпретатор python и менеджер пакетов pip.  
в будущем возможно добавление нового функционала и создание копии этого репозитория с переписанной логикой на язык "C". так же в каждом модуле и в исполняемом скрипте 
имеется подробное описание каждой строчки для подробного разбора логики работы. их я писал лично для себя как заметки что бы не забыть что выполняет
тот или иной модуль. 1 модуль с названием mykeylogger.py имеет лишь частичное описание работы потому что разбирать каждую строчку мне не требовалось.  
## установка и запуск
убедитесь что у вас есть python 3.8+ и менеджер установщик pip.
если нету то выполните следующие действия:  
откройте консоль cmd или powershell неважно.
для начала проверьте есть ли у вас интерпретатор python. введите следующую команду "python --version" если вывелась информация о python с версией выше 3.8 то можете переходить к следующему разделу.
а если версия интерпретатора ниже версии 3.8 или вывелась ошибка то читайте далее.
введите следующую команду "winget install Python.Python.3.13".
Дождитесь окончания загрузки и установки программы. Закройте текущее окно PowerShell и откройте его заново. Проверьте работоспособность командой:
"python --version". в случае ошибки прошу обратиться в документацию столько места здесь нет.
менеджер пакетов pip обычно устанавливается вместе с python но если возникли какие то проблемы то прошу документация в помощь.  
далее копируйте мой репозиторий и добавляйте в свой что бы он был вашим личным C2 сервером.
для работы трояна нужен только испоняемый файл telemetry_client.py а одноименный скрипт с репозитория можете удалить.
затем создайте файл именно с таким названием mytoken.txt, получите гитхаб токен старого образца и сохраните в этот файл.  
**ВАЖНО** что бы txt файл был в той же папке что и троян.
последним прошу вас зайти в telemetry_client.py и на 17 строчке кода там где переменная user вместо имени моего аккаунта прошу ввести имя вашего аккаунта иначе работать не будет.
затем запустите троян. все собранные данные будут в папке data, подпапке abc(так называется экземпляр трояна) и они будут называтся временем отправки данных.

## Структура проекта:
telemetry_client.py — основной файл.  
modules/ — папка с динамическими модулями на GitHub.  
config/ — конфигурационные файлы.  
data/ — сохранённые данные.  
mytoken.txt — токен для доступа к GitHub.  
## Безопасность
Все данные хранятся в приватном репозитории.  
Токен GitHub не должен попадать в открытый доступ.
